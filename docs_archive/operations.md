# Справочник операций (Operations Reference)

В этом разделе описаны все доступные операции для автоматизации в Adobe Illustrator.

## Доступные операции

*   [**Resize (Изменение размера)**](resizeOperation.md)
    *   Изменение ширины и высоты объектов.
    *   Поддержка различных единиц измерения (mm, px, pt, etc).
    *   Режимы: установка значения, увеличение, уменьшение.

*   [**Move (Перемещение)**](moveOperation.md)
    *   Позиционирование объектов на артборде.
    *   Абсолютное (в координаты) и относительное (сдвиг) перемещение.

*   [**Replace Object (Замена объектов)**](replaceOperation.md)
    *   Массовая замена объектов в документе на компоненты из библиотеки.
    *   Сохранение размеров и позиций заменяемых элементов.

*   [**Create Confection Card (Конфекционная карта)**](confectionCardOperation.md)
    *   Генерация спецификации деталей (таблицы) на основе JSON-данных.
    *   Поддержка различных визуальных стилей (layout).
    *   Автоматическая пагинация (создание новых артбордов).
    *   Поиск и подсветка имен деталей в документе.

*   [**Color (Цвет)**](colorOperation.md)
    *   *(В разработке)* Изменение заливки и обводки объектов.

## Общие принципы

Все операции наследуются от базового класса `BaseOperation` и имеют общую структуру вызова в JSON:

```json
{
  "type": "operationName",
  "parameters": {
    // Параметры, специфичные для конкретной операции
  }
}
```
