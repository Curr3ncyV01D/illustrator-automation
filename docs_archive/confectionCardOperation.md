# Операция: Создание Конфекционной карты (Confection Card)

Операция `createConfectionCard` предназначена для автоматической генерации спецификации деталей (конфекционной карты) на основе данных в формате JSON. Она создает новые артборды с таблицами, содержащими информацию о деталях кроя.

## Описание

Операция выполняет следующие действия:
1.  Принимает массив данных о деталях.
2.  Создает новый артборд (формат A4, вертикальный) справа от существующих.
3.  Отрисовывает таблицу с данными.
4.  Автоматически переносит данные на новые страницы (артборды), если количество строк превышает 25.
5.  Выполняет поиск объектов в документе по имени (`Pattern Name`) и выделяет их в таблице как гиперссылки (синим цветом с подчеркиванием), если объект найден.

## Параметры JSON

Операция ожидает следующий объект параметров в JSON-команде:

```json
{
  "type": "createConfectionCard",
  "parameters": {
    "style": { "template": "classic", "fontSize": 12, "rowHeight": 25 },
    "data": [
      // ...
    ]
  }
}
```

### Поля объекта `parameters`

| Поле | Тип | Описание |
|------|-----|----------|
| `style` | Object | (Опционально) Настройки стиля таблицы (`template`, `fontSize`, `rowHeight`). |
| `data` | Array | Массив объектов с данными для строк таблицы. |

### Поля объекта `data`

| Поле | Тип | Описание | Обязательность |
|------|-----|----------|----------------|
| `name` | String | Название детали. Значение на языке пользователя. | **Да** |
| `sort` | Number | Порядковый номер сортировки. | **Да** |
| `pattern_qty` | Number | Количество лекал. | **Да** |
| `cut_qty` | Number | Количество деталей кроя. | **Да** |
| `material` | String | Материал детали. | Нет |
| `size` | String | Размер. | Нет |

## Визуальный стиль

*   **Шапка таблицы**: Светло-голубая заливка (RGB: 180, 210, 235), жирный шрифт.
*   **Строки**: Высота 25pt, черные границы 0.5pt.
*   **Текст**:
    *   Имена деталей выровнены по левому краю.
    *   Числовые значения выровнены по центру.
    *   Если деталь найдена в документе, имя выделяется синим цветом и подчеркиванием.

## Использование

### Через Orchestrator (JSON файл)

```json
{
    "targetFile": "template.ai",
    "operations": [
        {
            "type": "createConfectionCard",
            "parameters": {
                "data": [
                    {"name": "Collar", "sort": 1, "pattern_qty": 1, "cut_qty": 1, "material": "Cotton", "size": "M"},
                    {"name": "Cuff", "sort": 2, "pattern_qty": 2, "cut_qty": 2, "material": "Cotton", "size": "M"}
                ]
            }
        }
    ]
}
```

### Прямой запуск (для тестирования)

Для тестирования можно использовать скрипт `examples/run_confection_card.jsx`.
Запустите его через меню `File -> Scripts -> Other Script...` в Adobe Illustrator.

## Технические детали

*   **Модуль**: `src/operations/confectionCardOperation.js`
*   **Класс**: `ConfectionCardOperation`
*   **Наследуется от**: `BaseOperation`
*   **Лимиты**: Максимум 25 строк на один артборд.
