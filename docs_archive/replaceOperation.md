# Операция: Замена объектов (Replace Operation)

Операция `replaceObject` позволяет заменять существующие объекты в документе на компоненты из внешних файлов. Поддерживает массовую замену по имени и автоматическое масштабирование.

## Описание

Операция ищет в текущем документе все объекты с указанным именем (или по шаблону) и заменяет их на копию "мастер-объекта" из другого файла. Это полезно для пакетного обновления компонентов, логотипов, или других повторяющихся элементов.

## Параметры JSON

Пример вызова операции:

```json
{
  "id": "replace_logo_1",
  "type": "replaceObject",
  "target": "OldLogo",
  "parameters": {
    "libraryFile": "Logos.ai",
    "sourceObject": "NewLogoVector",
    "matchTargetSize": true,
    "keepPosition": true,
    "scaleStroke": true
  }
}
```

### Структура параметров

| Параметр | Тип | Описание | Обязательный |
|----------|-----|----------|--------------|
| `libraryFile` | String | Имя файла-источника (в папке компонентов) | Да |
| `sourceObject` | String | Имя объекта-донора внутри файла-источника | Да |
| `matchTargetSize` | Boolean | Если true, новый объект масштабируется под размеры заменяемого объекта | Нет (default: `true`) |
| `keepPosition` | Boolean | Сохранять ли позицию (центр) заменяемого объекта | Нет (default: `true`) |
| `scaleStroke` | Boolean | Масштабировать ли толщину обводок при изменении размера | Нет (default: `true`) |
| `replaceContents` | Boolean | Если true и цель — группа, заменяет все объекты внутри неё. Если false, заменяет саму группу | Нет (default: `true`) |

> **Важно:** Все размеры и координаты обрабатываются через `Helpers.units`, передавать значения в командах (если применимо) нужно в **мм**.

### Особенности работы

1.  **Поиск целей**: Операция сканирует текущий документ на наличие объектов с именем `target` (указывается на одном уровне с `type`).
2.  **Загрузка источника**: 
    *   Скрипт ищет указанный `libraryFile` в локальных компонентах или глобальной библиотеке.
    *   В файле ищется объект с именем `sourceObject`.
    *   Этот объект дублируется в целевой документ.
3.  **Замена**:
    *   Если `target` является группой и `replaceContents: true`, операция выполняется для каждого вложенного объекта.
    *   Для каждого найденного целевого объекта:
        *   Вставляется копия нового объекта.
        *   Копия масштабируется под размеры старого объекта (если `matchTargetSize: true`).
        *   Копия позиционируется в центр старого объекта (если `keepPosition: true`).
        *   Масштабируется толщина обводки (если `scaleStroke: true`).
        *   Старый объект удаляется.

## Примеры

### Замена содержимого группы пуговиц
```json
{
  "id": "btn_replace_all",
  "type": "replaceObject",
  "target": "Group_Buttons",
  "parameters": {
    "libraryFile": "Buttons.ai",
    "sourceObject": "ModernButton",
    "replaceContents": true
  }
}
```

## Технические детали

*   **Файл реализации**: `src/operations/replaceOperation.js`
*   **Класс**: `ReplaceOperation`
*   **Наследуется от**: `BaseOperation`
*   **Зависимости**: `ObjectFinder`, `StyleScaler`

### Обработка ошибок
*   Если файл-источник не найден, операция прерывается.
*   Если объект-источник не найден, операция прерывается.
*   Если целевые объекты не найдены, выводится предупреждение, но операция считается успешной (ничего не сделано).
