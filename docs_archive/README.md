# 📚 Документация проекта Illustrator Automation

Добро пожаловать в документацию проекта автоматизации Adobe Illustrator. Здесь вы найдете всю необходимую информацию для использования, настройки и расширения системы.

## 🧭 Путеводитель по документации

Если вы хотите создать JSON-команду для автоматизации:

*   [**Справочник операций**](operations.md) — Полный список доступных действий (Resize, Move, Replace и т.д.).

### 🎨 Конфекционные карты и стили

Специфическая документация для генерации таблиц спецификаций:

*   [**Операция: Конфекционная карта**](confectionCardOperation.md) — Подробное описание операции `createConfectionCard` (параметры, данные).
*   [**Руководство по стилям**](styles_guide.md) — Инструкция по созданию и настройке визуальных стилей таблиц (цвета, шрифты, размеры).

### 🛠 Для разработчиков

Если вы хотите изменить код проекта или добавить новую функциональность:

*   [**Архитектура системы (Bridge & Dynamic Runner)**](architecture.md) — Описание Python-сервиса (Bridge), интеграции с Docker (n8n) и механизма Dynamic Runner.

## 📂 Структура проекта

*   `bridge/` — Модульный Python-сервис (FastAPI) для управления Illustrator и обработки очередей.
*   `exchange/` — Папка обмена данными с Docker (n8n).
*   `dev/` — Локальные ресурсы для разработки и тестирования (`input`, `output`, `tests`).
*   `src/` — Исходный код ExtendScript фреймворка.
*   `docs/` — Документация проекта.

*   `architecture.md` — Описание архитектуры Bridge и Dynamic Runner.
