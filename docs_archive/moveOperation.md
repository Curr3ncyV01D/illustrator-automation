# Операция: Перемещение (Move Operation)

Операция `move` позволяет изменять положение объектов на артборде. Поддерживает два режима перемещения: абсолютный (в конкретные координаты) и относительный (смещение).

## Описание

Позиционирует объект, используя заданные координаты `x` и `y`. Поддерживаются различные единицы измерения. Координаты считаются относительно центральной точки объекта (reference point = center) и левого верхнего угла артборда.

## Параметры JSON

Пример вызова операции:

```json
{
  "type": "move",
  "parameters": {
    "mode": "absolute",
    "x": {
      "value": 100,
      "unit": "mm",
      "action": "set"
    },
    "y": {
      "value": 50,
      "unit": "mm",
      "action": "set"
    }
  }
}
```

### Режимы (`mode`)

1.  **absolute**: Объект перемещается в точные координаты (X, Y). Требует `action: "set"`.
2.  **relative**: Объект смещается на заданное расстояние (dX, dY) от текущей позиции. Можно использовать `increase` (сдвиг вправо/вниз) или `decrease` (сдвиг влево/вверх).

### Структура параметров

| Параметр | Тип | Описание | Обязательный |
|----------|-----|----------|--------------|
| `mode` | String | `absolute` или `relative` | Да |
| `x` | Object | Координата X | Нет (если указан Y) |
| `y` | Object | Координата Y | Нет (если указан X) |

### Объект параметра координаты (x/y)

| Поле | Тип | Возможные значения | Описание |
|------|-----|-------------------|----------|
| `value` | Number | Число | Значение координаты или смещения |
| `unit` | String | `mm`, `cm`, `in`, `pt`, `px` | Единица измерения |
| `action` | String | `set`, `increase`, `decrease` | Тип действия (для relative) |

**Важно**: Для режима `absolute` поле `action` должно быть строго равно `set`.

## Особенности координат в Illustrator

*   **Ось Y**: В скриптах Illustrator ось Y направлена **вверх**.
    *   Положительное значение Y = движение вверх.
    *   Отрицательное значение Y = движение вниз.
*   Однако, в данной реализации `MoveOperation` может использоваться **инверсия Y** (если это заложено в `unitConverter` или логику перемещения, обычно для удобства пользователя Y=0 — это верхний левый угол, а Y>0 — смещение вниз).
    *   *Примечание*: В стандартном Illustrator API `top` координата уменьшается при движении вниз.
    *   Данная операция оперирует геометрическими координатами центра (`position`).

## Примеры

### Переместить объект в центр (100mm, 100mm)
```json
{
  "type": "move",
  "target": "Layer1/Logo",
  "parameters": {
    "mode": "absolute",
    "x": { "value": 100, "unit": "mm", "action": "set" },
    "y": { "value": 100, "unit": "mm", "action": "set" }
  }
}
```

### Сдвинуть объект на 10px вправо
```json
{
  "type": "move",
  "target": "Layer1/Button",
  "parameters": {
    "mode": "relative",
    "x": { "value": 10, "unit": "px", "action": "increase" }
  }
}
```
