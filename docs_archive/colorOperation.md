## Планируемая функциональность
Предполагается, что эта операция будет позволять изменять цвет заливки (`fillColor`) и обводки (`strokeColor`) объектов.

### Возможный формат параметров (Draft)

```json
{
  "type": "color",
  "parameters": {
    "fill": {
      "r": 255,
      "g": 0,
      "b": 0
    },
    "stroke": {
      "hex": "#FF0000"
    }
  }
}
```
