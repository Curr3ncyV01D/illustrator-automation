# Руководство по стилям конфекционных карт

Этот документ описывает процесс создания и настройки визуальных стилей для операции создания конфекционной карты (`createConfectionCard`).

## Где хранятся стили

Все стили определены в файле конфигурации:
`src/config/defaultSettings.js`

Внутри объекта `DefaultSettings` находится свойство `confectionCardStyles`, которое содержит определения всех доступных стилей.

## Структура стиля

Каждый стиль представляет собой объект со следующими свойствами:

```javascript
styleName: {
    headerColor: [R, G, B], // Массив из 3 чисел (0-255) для цвета RGB шапки
    rowHeight: Number,      // Высота строки таблицы в пунктах (pt)
    showBorders: Boolean,   // true - рисовать рамки, false - только текст
    fontSize: Number        // Размер шрифта в пунктах (pt)
}
```

### Описание параметров

| Параметр | Тип | Описание | Пример |
|---|---|---|---|
| `headerColor` | Array<Number> | Цвет заливки заголовка таблицы в формате RGB. | `[180, 210, 235]` (голубой) |
| `rowHeight` | Number | Высота каждой строки таблицы (включая шапку). | `25` |
| `showBorders` | Boolean | Определяет, нужно ли рисовать рамки вокруг ячеек. | `true` |
| `fontSize` | Number | Размер шрифта для текста в таблице. | `10` |

## Как добавить новый стиль

1.  Откройте файл `src/config/defaultSettings.js`.
2.  Найдите объект `confectionCardStyles`.
3.  Добавьте новую пару "ключ-значение", где ключ — это название вашего стиля, а значение — объект с настройками.

### Пример

Допустим, мы хотим создать стиль `dark_mode` с темной шапкой и белым текстом (обратите внимание, что цвет текста пока жестко задан как черный в операции, но мы можем настроить фон шапки).

```javascript
// src/config/defaultSettings.js

confectionCardStyles: {
    // ... существующие стили ...
    
    dark_mode: {
        headerColor: [50, 50, 50], // Темно-серый фон шапки
        rowHeight: 30,             // Чуть выше строки
        showBorders: true,
        fontSize: 12
    }
}
```

## Использование нового стиля

После добавления стиля в конфигурацию, его можно использовать в JSON-командах, передав его название в параметре `layout`.

```json
{
    "operation": "createConfectionCard",
    "parameters": {
        "layout": "dark_mode",
        "data": [ ... ]
    }
}
```

Если указанный стиль не найден, операция автоматически переключится на стиль `classic`.

## Рекомендации для разных форматов

При создании стилей для больших форматов бумаги (A3, A2 и т.д.) рекомендуется увеличивать размеры шрифта и высоту строки пропорционально увеличению размера листа (~1.41x для каждого следующего формата).

| Формат | Реком. Font Size | Реком. Row Height |
|---|---|---|
| A4 | 10pt | 25pt |
| A3 | 14pt | 35pt |
| A2 | 20pt | 50pt |
| A1 | 28pt | 70pt |
| A0 | 40pt | 100pt |
