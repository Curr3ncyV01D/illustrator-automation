# Операция: Изменение размера (Resize Operation)

Операция `resize` позволяет изменять размеры объектов (ширину и высоту) с возможностью сохранения пропорций. Поддерживает различные единицы измерения и режимы изменения (установка точного значения, увеличение или уменьшение).

## Описание

Операция выполняет изменение размера выбранного объекта относительно его центра. Можно изменять ширину и высоту независимо друг от друга.

## Параметры JSON

Пример вызова операции в JSON-команде:

```json
{
  "type": "resize",
  "target": "Layer1/MyObject",
  "parameters": {
    "width": {
      "value": 100,
      "unit": "mm",
      "action": "set"
    },
    "height": {
      "value": 50,
      "unit": "pt",
      "action": "increase"
    }
  }
}
```

### Структура параметров

| Параметр | Тип | Описание | Обязательный |
|----------|-----|----------|--------------|
| `width` | Object | Параметры изменения ширины | Нет (если указан height) |
| `height` | Object | Параметры изменения высоты | Нет (если указан width) |

### Объект параметра размера (width/height)

| Поле | Тип | Возможные значения | Описание |
|------|-----|-------------------|----------|
| `value` | Number | Любое число | Значение размера или изменения |
| `unit` | String | `mm`, `cm`, `in`, `pt`, `px` | Единица измерения |
| `action` | String | `set`, `increase`, `decrease` | Тип действия |

### Типы действий (`action`)

*   **set**: Устанавливает точный размер объекта (например, сделать ширину ровно 100mm).
*   **increase**: Увеличивает текущий размер на указанное значение (например, добавить 10mm к текущей ширине).
*   **decrease**: Уменьшает текущий размер на указанное значение.

## Особенности поведения

1.  **Центрирование**: Изменение размера происходит относительно центральной точки объекта (reference point = center). Объект не смещается визуально, он растет или сжимается "из центра".
2.  **Пропорции**: Если указан только один параметр (например, только `width`), высота объекта **не изменится** автоматически пропорционально. Чтобы сохранить пропорции, необходимо самостоятельно рассчитать и передать оба значения, либо (в будущих версиях) использовать флаг `constrainProportions`.
3.  **Валидация**: 
    *   Проверяется, что `value` является числом.
    *   Проверяется допустимость единиц измерения.
    *   Проверяется допустимость действия (`action`).

## Примеры

### Установить точный размер 50x50 мм
```json
{
  "type": "resize",
  "target": "Layer1/Box",
  "parameters": {
    "width": { "value": 50, "unit": "mm", "action": "set" },
    "height": { "value": 50, "unit": "mm", "action": "set" }
  }
}
```

### Увеличить ширину на 10 пунктов
```json
{
  "type": "resize",
  "target": "Layer1/TextFrame",
  "parameters": {
    "width": { "value": 10, "unit": "pt", "action": "increase" }
  }
}
```
