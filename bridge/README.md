# Bridge Service (Modular Version)

Этот каталог содержит модульную версию сервиса Bridge, написанную на FastAPI. Сервис служит прослойкой между внешними системами (n8n, Docker) и Adobe Illustrator.

## Структура каталога

- **`main.py`** — Точка входа в приложение. Содержит определение эндпоинтов и управление фоновыми задачами.
- **`config.py`** — Конфигурация сервиса (пути, таймауты, ключи API).
- **`models.py`** — Pydantic-модели для валидации входящих запросов и ответов.
- **`services/`** — Основная бизнес-логика:
    - `illustrator.py` — Управление процессом Illustrator через COM, запуск скриптов с watchdog-таймером.
    - `workspace.py` — Подготовка рабочей области задачи, нормализация путей, создание runner-скриптов.
- **`utils/`** — Вспомогательные модули:
    - `logger.py` — Настройка логирования.
    - `security.py` — Проверка API ключей.
    - `log_analyzer.py` — Анализ логов ExtendScript для выявления ошибок.

## Запуск

Для запуска сервиса рекомендуется использовать `uvicorn`:

```bash
python -m uvicorn bridge.main:app --host 0.0.0.0 --port 8000
```
