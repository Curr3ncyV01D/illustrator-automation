# Руководство пользователя: n8n и Инфраструктура

В этом разделе описаны практические шаги по развертыванию, обслуживанию и обновлению системы оркестрации на базе n8n.

---

## 1. Развертывание системы

Вся инфраструктура n8n упакована в Docker. Для запуска выполните следующие шаги:

1. **Убедитесь, что Docker Desktop запущен** на вашей Windows-машине.
2. **Откройте терминал** в корне проекта (`C:/illustrator-automation/`).
3. **Запустите контейнеры**:
   ```bash
   docker-compose up -d
   ```
   Флаг `-d` запустит n8n в фоновом режиме. После этого интерфейс будет доступен по адресу: `http://localhost:5678`.

---

## 2. Сброс очереди Telegram (Offset)

Система запоминает последнее обработанное сообщение, чтобы не обрабатывать его повторно. Если вам нужно заставить бота "увидеть" старые сообщения (например, после сбоя или для повторного теста):

1. Перейдите в папку `exchange/` в корне проекта.
2. Найдите файл `last_offset.txt`.
3. **Удалите этот файл** или очистите его содержимое.
4. При следующем запуске воркфлоу n8n начнет чтение сообщений с самого начала доступной истории Telegram (обычно последние 24 часа).

---

## 3. Обновление токенов и ключей

Все секретные данные хранятся в файле `.env` и пробрасываются в Docker.

### Как обновить TELEGRAM_BOT_TOKEN или BRIDGE_API_KEY:
1. Откройте файл `.env` в корне проекта.
2. Отредактируйте нужные строки (см. [таблицу переменных окружения](reference.md#2-переменные-окружения-env)):
   ```env
   TELEGRAM_BOT_TOKEN=8538437617:AAFzo... (ваш новый токен)
   BRIDGE_API_KEY=GOROX321 (ваш новый ключ)
   ```
3. **Важно**: После изменения `.env` необходимо перезапустить контейнеры, чтобы изменения вступили в силу:
   ```bash
   docker-compose up -d
   ```

---

## 4. Экспорт и Импорт воркфлоу

Чтобы сохранить текущую схему автоматизации или перенести её на другой сервер:

### Экспорт:
1. Откройте воркфлоу в интерфейсе n8n.
2. Нажмите на иконку меню (три точки) в верхнем правом углу.
3. Выберите **Download JSON**. Файл будет сохранен на ваш компьютер.

### Импорт:
1. Создайте новый пустой воркфлоу в n8n.
2. Нажмите на меню (три точки) -> **Import from File**.
3. Выберите сохраненный ранее JSON-файл.
4. Нажмите **Save**, чтобы применить изменения.

## 5. Troubleshooting (Решение проблем)

Если система работает некорректно, проверьте следующие моменты:

- **Бот не отвечает**: 
  - Проверьте статус Docker-контейнеров (`docker ps`). n8n должен быть в статусе `Up`.
  - Убедитесь, что в файле `.env` указан верный `TELEGRAM_BOT_TOKEN`.
  - Попробуйте [сбросить очередь](how_to.md#2-сброс-очереди-telegram-offset), удалив файл `last_offset.txt`.
- **Illustrator висит (завис)**: 
  - Проверьте окно Adobe Illustrator на хост-машине. Возможно, открыто модальное окно (ошибка шрифтов, предложение войти в Cloud или предупреждение о версии), которое блокирует выполнение скриптов.
  - Убедитесь, что `userInteractionLevel` в настройках моста установлен в значение `-1` (dontDisplayAlerts).
- **Файлы не отправляются**: 
  - Проверьте права доступа n8n к папке `/data/exchange/`. 
  - Убедитесь, что папка `exchange` на Windows не заблокирована другим процессом.
  - Проверьте логи в n8n на наличие ошибок доступа к файловой системе.

---

## 6. Обновление n8n

Чтобы обновить n8n до последней версии в Docker, выполните последовательность команд:

```bash
docker-compose pull
docker-compose up -d
```
Это загрузит свежий образ и перезапустит контейнеры с сохранением всех данных и настроек.
