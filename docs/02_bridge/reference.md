# Технический справочник: Bridge

Данный раздел описывает Мост — связующее звено между n8n и Illustrator.

Этот документ содержит техническую информацию о компоненте **Bridge**, который выступает посредником между Node.js сервисом и Adobe Illustrator.

## Структура папки `bridge/`

```text
bridge/
├── services/
│   ├── illustrator.py # Управление COM-объектом и процессами
│   └── workspace.py   # Работа с файлами, путями и валидация
├── utils/
│   ├── logger.py      # Логирование
│   └── security.py    # Проверка API-ключа
├── config.py          # Настройки (API Key, пути, таймауты)
├── main.py            # Точка входа FastAPI (маршруты)
└── models.py          # Pydantic модели (схемы запросов)
```

## 1. Архитектура и назначение

Компонент построен на базе **FastAPI** и использует **PyWin32** для взаимодействия с Adobe Illustrator через COM-интерфейс.

| Файл / Папка | Назначение |
| :--- | :--- |
| [main.py](/bridge/main.py) | Точка входа приложения. Определяет маршруты FastAPI и логику обработки фоновых задач. |
| [models.py](/bridge/models.py) | Определение схем данных Pydantic для валидации входящих запросов и исходящих ответов. |
| [config.py](/bridge/config.py) | Глобальные настройки, пути к директориям и переменные окружения. |
| `services/` | Основная бизнес-логика: взаимодействие с Illustrator и управление рабочим пространством. |
| [illustrator.py](/bridge/services/illustrator.py) | Сервис для управления процессом Illustrator и выполнения JavaScript-скриптов. |
| [workspace.py](/bridge/services/workspace.py) | Логика подготовки директорий для заданий, нормализация путей и очистка. |
| `utils/` | Вспомогательные инструменты: логирование, безопасность и анализ логов. |
| [security.py](/bridge/utils/security.py) | Проверка API-ключа (`X-API-Key`) для защиты эндпоинтов. |
| [logger.py](/bridge/utils/logger.py) | Конфигурация логирования в файл и консоль. |
| [log_analyzer.py](/bridge/utils/log_analyzer.py) | Анализ логов Illustrator после выполнения задания для выявления ошибок. |

### Структура общих ресурсов

| Папка | Назначение |
| :--- | :--- |
| `exchange/library/` | Хранилище общих ресурсов: фурнитура, логотипы, компоненты и шаблоны, доступные для всех задач. |
| `exchange/jobs/` | Временные директории для выполнения конкретных заданий (создаются динамически). |

## 2. Системные зависимости

Для корректной работы Bridge на Windows-хосте необходимо соблюдение следующих условий:

### Программное обеспечение
- **Adobe Illustrator**: Версия 2022+ (необходим доступ к COM-интерфейсу).
- **Python 3.10+**: Должен быть установлен **«Для всех пользователей»** (Add Python to PATH) для корректной регистрации COM-серверов.
- **Библиотека PyWin32**: Критически важная зависимость для взаимодействия с Windows API и Illustrator.Application.

### Права и доступ
- **Реестр Windows**: Процесс Python должен иметь достаточные права для чтения веток реестра, связанных с регистрацией COM-объектов Adobe.
- **Интерактивный сеанс**: Illustrator — графическое приложение, поэтому мост должен запускаться под учетной записью пользователя, имеющего активный рабочий стол (не как служба без GUI).
- **Файловая система**: Права на чтение/запись в папку `exchange/` для обмена данными с Docker.

## 3. API Эндпоинты

Все эндпоинты требуют заголовок `X-API-Key` для авторизации.

| Метод | Путь | Описание | Ожидаемые HTTP-статусы |
| :--- | :--- | :--- | :--- |
| `GET` | `/status` | Проверка текущего состояния моста (занят или свободен). | `200` (OK), `401` (Unauthorized) |
| `POST` | `/process` | Прием нового задания на обработку в Illustrator. | `200` (Accepted), `400` (Bad Request), `401` (Unauthorized), `403` (Forbidden), `429` (Too Many Requests) |

---

## 4. Healthcheck Мониторинг

Эндпоинт `/status` можно использовать для автоматизированного контроля доступности моста внешними системами мониторинга (например, UptimeRobot, Zabbix или Prometheus).

### Проверка работоспособности:
- **URL**: `http://<host>:8000/status`
- **Заголовок**: `X-API-Key: <your-key>`
- **Метод**: `GET`

### Интерпретация результатов:
- **HTTP 200**: Мост запущен и отвечает на запросы. В теле ответа содержится информация о текущей занятости (`is_busy`).
- **HTTP 401**: Мост доступен, но заголовок API-ключа неверный или отсутствует.
- **Connection Refused**: Bridge не запущен на хост-машине.
- **Timeout**: Сервер не отвечает (возможные причины: зависание Python-процесса или проблемы с сетью).

Рекомендуется настроить уведомления на любые статусы, отличные от 200, для оперативного реагирования на падение сервиса на Windows-хосте.

### Детализация статусов `POST /process`:
- **200**: Задание принято и добавлено в фоновую очередь.
- **400**: Неверный формат данных или невалидный `job_id`.
- **401**: Отсутствует или неверный API-ключ.
- **403**: Попытка доступа к файлам вне разрешенной директории (Path Traversal).
- **429**: Мост уже занят обработкой другого задания (лимит — 1 параллельное задание).

## 3. API Спецификация (Pydantic Модели)

Система обменивается данными в формате JSON. Ниже представлены структуры запросов и ответов.

**3.1. Запрос на обработку (`POST /process`)**
Используется для постановки задачи в очередь.

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `job_id` | `string` | Уникальный ID задачи (соответствует имени папки). |
| `file_path` | `string` | Абсолютный путь к `.ai` файлу в формате Docker (`/data/exchange/...`). |
| `commands` | `object` | Словарь с инструкциями для ExtendScript (согласно `Dict[str, Any]` в Pydantic; См. раздел [ExtendScript Operations](../03_extendscript/reference.md#3-реестр-операций-operation-registry).) |

**Пример запроса:**
```json
{
  "job_id": "job_1772925893",
  "file_path": "/data/exchange/jobs/job_1772925893/input/source_files/template.ai",
  "commands": {
    "version": "1.0",
    "operations": [
      {
        "id": "op_01",
        "type": "resize",
        "parameters": {
          "width": 150,
          "height": 100
        }
      }
    ]
  }
}
```

---

**3.2. Статус сервиса (`GET /status`)**
Используется для проверки занятости Illustrator перед отправкой нового задания.

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `status` | `string` | Текстовый статус: `"idle"` (свободен) или `"busy"` (занят). |
| `is_busy` | `boolean` | Флаг готовности: `true` — выполнение задачи, `false` — ожидает новых команд. |

**Пример ответа:**
```json
{
  "status": "idle",
  "is_busy": false
}
```

## 4. Конфигурация и Окружение (.env)

Для запуска моста необходимо настроить следующие переменные окружения в файле `.env` (или передать их напрямую):

| Переменная | Тип | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `BRIDGE_API_KEY` | `str` | `"dev-key"` | Ключ для авторизации запросов в заголовке `X-API-Key`. |
| `BRIDGE_JOB_TIMEOUT_SECONDS` | `int` | `300` | Максимальное время выполнения одного задания (в секундах). |

### Внутренние константы путей:
- `BASE_DIR`: Корень проекта.
- `EXCHANGE_DIR`: Директория для обмена файлами (`/exchange`).
- `BASE_JOBS_DIR`: Путь к папке заданий (`/exchange/jobs`).
- `DOCKER_PREFIX`: Префикс путей внутри контейнера (`/data/exchange`).
Настройки считываются в [config.py](/bridge/config.py).
