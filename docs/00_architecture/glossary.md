# Глоссарий системы

В данном документе приведены определения ключевых терминов и концепций, используемых в архитектуре проекта Illustrator Automation.

---

### COM/OLE Automation
Технология Windows, позволяющая внешним приложениям (в нашем случае Python-мосту) программно управлять Adobe Illustrator «снаружи», имитируя действия пользователя или вызывая внутренние методы API.

### Confection Card (Конфекционная карта)
Итоговый технический документ в формате PDF, генерируемый системой. Содержит описание материалов, фурнитуры изделия и визуализацию готового лекала.

### Early Exit (Ранний выход)
Логика оркестратора n8n, позволяющая немедленно прервать цикл ожидания результата, если в логах задачи обнаружен тег `[ERROR]`, не дожидаясь истечения общего таймаута.

### ExtendScript (JSX)
Язык программирования (расширение стандарта ECMAScript 3), который исполняется непосредственно внутри Adobe Illustrator. Используется для прямого манипулирования объектами чертежа (DOM).

### Facade Pattern (Фасад)
Паттерн проектирования, применяемый в ExtendScript для скрытия сложной внутренней логики геометрических преобразований за простым и понятным набором высокоуровневых команд.

### Handshake (Рукопожатие)
Процесс ожидания физического появления файлов на диске Windows перед началом обработки. Необходим для компенсации задержки синхронизации между Docker-контейнером и файловой системой хоста.

### Headless Mode (Режим без диалогов)
Режим работы Adobe Illustrator (уровень взаимодействия `UserInteractionLevel.DONTDISPLAYALERTS`), при котором подавляются все всплывающие окна, предупреждения и диалоги, требующие вмешательства человека.

### Job ID
Уникальный идентификатор рабочей сессии, генерируемый в n8n на основе временной метки. Используется как имя корневой папки задачи в системе обмена данными.

### Manual Polling (Опрос)
Метод взаимодействия с Telegram API, при котором система регулярно запрашивает новые сообщения через метод `getUpdates`. Это позволяет работать без публичного IP-адреса и входящих вебхуков.

### Media Group ID
Уникальный ключ Telegram, который связывает несколько файлов (например, исходный `.ai` и конфигурационный `.json`), если они были отправлены пользователем в одном сообщении (альбоме).

### Offset (Смещение)
Числовой идентификатор последнего успешно обработанного сообщения в Telegram. Используется при опросе (Polling) для предотвращения повторной загрузки и обработки уже выполненных задач.

### Path Traversal (Инъекция путей)
Вид кибератаки, направленный на доступ к файлам за пределами разрешенной директории. В проекте блокируется путем строгой валидации и резолвинга путей через `pathlib.resolve()`.

### Point vs Millimeter (Конвертация единиц)
Процесс пересчета размеров между типографскими пунктами (в которых работает Illustrator) и промышленными миллиметрами, выполняемый через модуль `unitConverter`.

### Registry Pattern (Реестр)
Архитектурный паттерн в ExtendScript, позволяющий динамически регистрировать и подключать новые типы графических операций без изменения основного ядра системы.

### Раннер (runner.jsx)
Временный файл-запускатор, создаваемый Мостом для передачи контекста задачи (Job ID) в среду Иллюстратора. Он служит точкой входа и инициализирует глобальные переменные, необходимые для работы Ядра.

### SaaS Scalability (Масштабируемость)
Архитектурная возможность системы наращивать производительность путем добавления новых Windows-узлов (Worker Nodes) с запущенным Illustrator под управлением единого центра n8n.

### Shared Volume (Общий том)
Технология Docker, обеспечивающая доступ к одной и той же папке на диске как для Linux-контейнера (n8n), так и для хост-системы Windows (Python Bridge / Illustrator).

### Style Scaler (Масштабирование)
Внутренний программный модуль в ExtendScript, отвечающий за пропорциональное изменение размеров элементов одежды с сохранением критических технологических отступов и припусков.

### Target Object (Целевой объект)
Конкретный элемент чертежа (слой, группа, путь или текстовый блок), к которому применяется графическая операция, определенная в JSON-команде.

### Watchdog (Сторожевой таймер)
Механизм в Python-мосте, который осуществляет мониторинг времени выполнения скрипта в Illustrator и принудительно завершает процесс при превышении заданного лимита (Timeout).

### Zombie Process (Зомби-процесс)
Зависший в памяти процесс `Illustrator.exe`, который перестал отвечать на команды через COM-интерфейс, блокирует ресурсы и подлежит принудительной очистке со стороны Python-моста.
